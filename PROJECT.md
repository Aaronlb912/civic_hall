# CivicHall

Drupal.org project application notes. Not part of the packaged recipe.

`civic_hall`

## Composer name

`drupal/civic_hall`

The Mercury subtheme is a second project: short name `civic_hall_theme`, Composer name `drupal/civic_hall_theme`, project type Theme.

## Project type

Recipe, if the form offers it. Otherwise a general project. Composer type is `drupal-recipe`. Recipe type in `recipe.yml` is `Site`.

## Description

Designed for clerks and one-person IT shops, this template features How do I, departments, meetings and news, with city alerts, search and a contact form.
